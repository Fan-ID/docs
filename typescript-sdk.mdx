Install the official **`soundlink`** package to call the Public API with full TypeScript types. For raw HTTP, see [Quickstart](/quickstart). Not sure which approach fits your stack? See [Official SDKs](/sdks).

## Prerequisites

- API key (`sk_*`) with the scopes you need — [Authentication](/authentication)
- `PUBLIC_API_ENABLED` for your organization (Soundlink Engineering)
- **Node.js 18+** or an Edge runtime with `fetch`

Store the key in an environment variable (e.g. `SOUNDLINK_API_KEY`). Never hardcode keys or ship them to the browser.

## 1. Install

<CodeGroup>

```bash npm
npm install soundlink
```

```bash yarn
yarn add soundlink
```

```bash pnpm
pnpm add soundlink
```

```bash bun
bun add soundlink
```

</CodeGroup>

## 2. Initialize the client

```typescript
import { Soundlink } from 'soundlink';

const soundlink = new Soundlink({
  apiKey: process.env.SOUNDLINK_API_KEY!,
});
```

You can also pass the key as a string: `new Soundlink('sk_your_prefix_your_secret')`.

The client sends `x-api-key` on every request. Your organization is determined from the key.

## 3. Ping and list campaigns

```typescript
const { data, error, meta } = await soundlink.ping();
if (error) {
  console.error(error.message, meta?.requestId);
  process.exit(1);
}

const { data: campaigns, error: listError } = await soundlink.campaigns.list({
  page: 1,
  pageSize: 100,
  sortBy: 'createdAt',
  sortOrder: 'desc',
});

if (listError) {
  console.error(listError.code, listError.message);
}
```

List campaigns requires the `campaigns:read` scope. Equivalent `curl` examples are in [Quickstart](/quickstart).

### Paginate all campaigns

```typescript
for await (const campaign of soundlink.campaigns.listAll({ pageSize: 100 })) {
  console.log(campaign.campaignId);
}
```

## Response pattern

Every method returns `{ data, error, meta? }` — the same envelope as the REST API. HTTP errors are **not thrown**; check `error` and use `requestId` when contacting support. See [Errors](/errors).

<Note>
  Do not use `try/catch` for normal API failures. The SDK only throws for configuration, parse, or transport errors.
</Note>

## Metrics and exports

```typescript
const { data: overview } = await soundlink.metrics.overview('camp_abc123', {
  startDate: '2026-01-01',
  endDate: '2026-03-31',
});

const { data: stream } = await soundlink.metrics.breakdown.export('camp_abc123', {
  startDate: '2026-01-01',
  endDate: '2026-03-31',
});

if (stream) {
  for await (const row of stream) {
    await warehouse.insert(row);
  }
}
```

For smaller datasets: `await soundlink.metrics.breakdown.export.collect('camp_abc123')`.

See [Understanding metrics](/understanding-metrics) for which endpoint to call and [JSONL exports](/jsonl-exports) for date windows and pipeline patterns.

## Configuration

```typescript
const soundlink = new Soundlink({
  apiKey: process.env.SOUNDLINK_API_KEY!,
  baseUrl: 'https://api.getsoundlink.com', // default
  timeout: 30_000,
  maxRetries: 2,
  fetch: customFetch, // optional — tests or Edge
});
```
