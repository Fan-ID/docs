title: MCP server
description: Connect an AI client to your Soundlink organization over Streamable HTTP.

MCP lets an AI client call Soundlink on your behalf. Soundlink hosts the server. There is nothing to install.

```
https://api.getsoundlink.com/mcp
```

Use any client that speaks **Streamable HTTP**. The server forwards your bearer token to the Public API and returns read-only data. It does not create campaigns, change budgets, or import videos.

## OAuth

Clients that can open a browser sign in with [Soundlink OAuth](/set-up-soundlink-oauth). Soundlink does not support dynamic client registration. Register an OAuth app under **Settings → OAuth apps** with grant type **Authorization code**, the redirect URI your client shows you, and the scopes you need. Paste that app's client id and client secret into the MCP client.

Access tokens last one hour. Soundlink does not issue refresh tokens. When a token expires, sign in again. One connection is one organization. To use another org, disconnect and approve that org on the consent screen.

## API key

If the client cannot open a browser, send an API key as a bearer token. Create the key in **Settings → Developer → API keys** with the scopes below. See [Authentication](/authentication).

```json
{
  "mcpServers": {
    "soundlink": {
      "url": "https://api.getsoundlink.com/mcp",
      "headers": {
        "Authorization": "Bearer sk_your_key"
      }
    }
  }
}
```

## Cursor

Open **Cursor Settings → MCP → Add new global MCP server**. For OAuth, omit the header and complete the login the client starts:

```json
{
  "mcpServers": {
    "soundlink": {
      "url": "https://api.getsoundlink.com/mcp"
    }
  }
}
```

In Claude, add a custom connector with the same URL.

## Tools

The scope is whatever the API requires for that route. A missing scope comes back as the API error, not a generic failure.

| Tool | Public API | Scope |
| --- | --- | --- |
| `ping` | `GET /v1/ping` | any valid credential |
| `get_campaigns` | `GET /v1/campaigns` | `campaigns:read` |
| `get_campaign` | `GET /v1/campaigns/{campaignId}` | `campaigns:read` |
| `get_campaign_tiers` | `GET /v1/campaigns/{campaignId}/tiers` | `campaigns:read` |
| `get_campaign_metrics_overview` | `GET /v1/campaigns/{campaignId}/metrics/overview` | `metrics:read` |
| `get_campaign_metrics_creatives` | `GET /v1/campaigns/{campaignId}/metrics/creatives` | `metrics:read` |
| `get_campaign_metrics_breakdown` | `GET /v1/campaigns/{campaignId}/metrics/breakdown` | `metrics:read` |
| `get_campaign_metrics_engagement` | `GET /v1/campaigns/{campaignId}/metrics/engagement` | `metrics:read` |
| `get_campaign_metrics_breakdown_export` | `GET /v1/campaigns/{campaignId}/metrics/breakdown/export` | `metrics:read` |
| `get_campaign_metrics_engagement_export` | `GET /v1/campaigns/{campaignId}/metrics/engagement/export` | `metrics:read` |
| `get_soundlinks` | `GET /v1/soundlinks` | `soundlinks:read` |
| `get_soundlink` | `GET /v1/soundlinks/{soundlinkId}` | `soundlinks:read` |
| `get_soundlink_metrics_overview` | `GET /v1/soundlinks/{soundlinkId}/metrics/overview` | `soundlinks:read` |
| `get_soundlink_metrics_breakdown` | `GET /v1/soundlinks/{soundlinkId}/metrics/breakdown` | `soundlinks:read` |
| `get_soundlink_metrics_engagement` | `GET /v1/soundlinks/{soundlinkId}/metrics/engagement` | `soundlinks:read` |
| `get_soundlink_metrics_breakdown_export` | `GET /v1/soundlinks/{soundlinkId}/metrics/breakdown/export` | `soundlinks:read` |
| `get_soundlink_metrics_engagement_export` | `GET /v1/soundlinks/{soundlinkId}/metrics/engagement/export` | `soundlinks:read` |
| `get_strategies` | `GET /v1/strategies` | `campaigns:read` |
| `get_wallet` | `GET /v1/wallet` | `wallet:read` |

`get_campaign_tiers` only succeeds for a wallet campaign. Engagement tools take an optional `engagementContext` of `catalog` or `playlist`. Exports default to the last 90 days and return JSONL, not the JSON envelope. `get_soundlinks` does not include soundlinks created for a campaign.

Field definitions: [Campaign metrics](/understanding-metrics), [Soundlink metrics](/soundlink-metrics), [JSONL exports](/jsonl-exports).
