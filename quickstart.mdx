Get your first successful API response in a few minutes with `curl`. Using Node.js or TypeScript? See [Access the API with TypeScript](/typescript-sdk) instead.

## Prerequisites

- A Soundlink account with **owner** or **admin** access to your organization
- An API key (`sk_*`) — create one in the app (below) or use an existing key

## 1. Ping (connectivity)

Replace `sk_YOUR_PREFIX_YOUR_SECRET` with the key you copied from the **Save your API key** dialog:

```bash
curl -sS 'https://api.getsoundlink.com/v1/ping' \
  -H 'x-api-key: sk_YOUR_PREFIX_YOUR_SECRET'
```

Expected:

```json
{
  "data": { "status": "ok" },
  "meta": { "requestId": "..." }
}
```

Ping accepts any valid key scope (`campaigns:read` and/or `metrics:read`).

## 2. List campaigns

Requires the `campaigns:read` scope on your key.

```bash
curl -sS 'https://api.getsoundlink.com/v1/campaigns?page=1&pageSize=10' \
  -H 'x-api-key: sk_YOUR_PREFIX_YOUR_SECRET'
```

## 3. Use requestId for support

If something fails, include `meta.requestId` from the error response when contacting Soundlink support. See [Errors](/errors) for common codes.
