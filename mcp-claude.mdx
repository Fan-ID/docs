Claude connects to Soundlink through the official directory listing. Access is read-only. Claude identifies itself with a Client ID Metadata Document (CIMD), so you do not create an OAuth app.

## 1. Install from the Claude Directory

1. Open the [Soundlink listing in the Claude Directory](https://claude.ai/directory/soundlink).
2. Add the connector.
3. Complete the browser login and approve one organization.

## 2. Check the connection

Ask Claude to call `ping`. A working connection returns `{"status":"ok"}`. Then ask for a campaign list. For the full tool list and scopes, see the [MCP overview](/mcp-server#tools).

## Custom connector fallback

If you cannot use the Directory, open **Settings → Connectors → Add custom connector** and paste:

```
https://api.getsoundlink.com/mcp
```

Complete the OAuth login in the browser.
