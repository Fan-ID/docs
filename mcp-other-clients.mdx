Any client that speaks **Streamable HTTP** can use the same endpoint:

```
https://api.getsoundlink.com/mcp
```

For Claude and Cursor, see [Claude Directory](/mcp-claude) and the [Cursor plugin](/mcp-cursor). This page covers any other client that accepts a remote MCP URL.

## CIMD browser login

If the client supports a Client ID Metadata Document (CIMD), paste the MCP URL and complete the browser login. You do not create an OAuth app.

If the client does not request specific scopes, Soundlink grants your identity and read access only (`openid`, `email`, and each `:read` scope).

If Soundlink does not recognize the app, the consent screen says it is not verified and shows the host it will send you back to. Check that host before you approve.

## API key

If the client cannot open a browser, send the key as `Authorization: Bearer sk_your_key`.

Create the key in [Settings → Developer → API keys](https://getsoundlink.com/settings/developer) with `campaigns:read`, `metrics:read`, `soundlinks:read`, and `wallet:read`. Add `pixels:read` for `get_pixels`.

Example config:

```json
{
  "mcpServers": {
    "soundlink": {
      "url": "https://api.getsoundlink.com/mcp",
      "headers": {
        "Authorization": "Bearer sk_your_key"
      }
    }
  }
}
```

## OAuth app

Use this when the client asks for a client id and secret and does not use CIMD.

<Steps>
  <Step title="Open OAuth apps">
    Go to [Settings → Developer → OAuth
    apps](https://getsoundlink.com/settings/oauth-apps).
  </Step>
  <Step title="Create the app">
    Set a name. Enable the **Authorization code** grant. Paste the redirect URI
    your MCP client shows you — it must match exactly, including `http` vs
    `https` and `localhost` vs `127.0.0.1`. Select the scopes above.
  </Step>
  <Step title="Copy the client id and secret">
    Paste both into the MCP client. The secret is shown once. Access tokens last
    one hour. The client refreshes them, so you stay connected without signing
    in again. See [OAuth](/set-up-soundlink-oauth).
  </Step>
</Steps>

Soundlink does not support RFC 7591 dynamic client registration. Clients that try to register at runtime still need an API key or an OAuth app.

OAuth-only config:

```json
{
  "mcpServers": {
    "soundlink": {
      "url": "https://api.getsoundlink.com/mcp"
    }
  }
}
```

## Check the connection

Ask the client to call `ping`. A working credential returns `{"status":"ok"}`. For the full tool list and scopes, see the [MCP overview](/mcp-server#tools).
